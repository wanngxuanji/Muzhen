# TransApp v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `TransApp` v1 — a Windows desktop application that extracts frame-accurate subtitle timelines and Simplified Chinese OCR text from single hardsubbed (`白字黑边`) anime/donghua video episodes and exports clean `.ass` (Aegisub) and `.srt` (Adobe Premiere Pro) files.

**Architecture:** Single-episode streaming pipeline in Python 3.11 using `PyAV` for PTS-accurate ROI decoding without requiring system `ffmpeg`, OpenCV HSV+outline masking with a bounded ring-buffer segmenter to avoid splitting lines over bright moving anime backgrounds, `RapidOCR` (`PP-OCRv4` Chinese) with text-similarity post-processing, and a `PySide6` desktop UI with in-memory review thumbnails and JSON ROI presets.

**Tech Stack:** Python 3.11.9, PySide6, PyAV (`av`), OpenCV (`opencv-python-headless`), NumPy, RapidOCR (`rapidocr-onnxruntime`), ONNX Runtime (`onnxruntime`, with optional `onnxruntime-directml` benchmark), `pytest`, `pytest-qt`.

**Spec:** [2026-11-27-transapp-design.md](file:///d:/Code%20Project/TransApp/docs/superpowers/specs/2026-11-27-transapp-design.md)

## Global Constraints

- OS & Hardware target: Windows, Intel Core Ultra 7 255HX, 16 GB RAM, NVIDIA GeForce RTX 5060 Laptop GPU (`Python 3.11.9` installed; `ffmpeg` is NOT in `PATH`, `uv` is NOT installed).
- Single-episode workflow per run (no multi-episode batch queue, no persisted episode project cache on disk; review thumbnails stay in memory and clear on video switch/app exit).
- Video folder stays clean: only export `<video_stem>.ass` and `<video_stem>.srt` (presets stored in user/app config folder, never inside video directories).
- v1 scope strictly excludes audio ASR/Whisper, AI translation/LLM calls, MCP servers, and Aegisub GUI control.
- Do not commit large sample MP4 files in `assets/` (`assets/【官方Official】战斗王之飓风战魂2_第01集 — Infinity Nado 2 _ Episode 01.mp4` [130,845,565 bytes] and `assets/【官方Official】战斗王之飓风战魂2_第01集 — Infinity Nado 2 _ Episode 01 copy.mp4` [193,065,679 bytes]).
- All text/subtitle files must use UTF-8 and handle Windows Unicode/Chinese/space/em-dash file paths cleanly.

## Review Focus

1. **Unicode/Chinese/em-dash/spaced Windows paths** (such as `assets/【官方Official】战斗王之飓风战魂2_第01集 — Infinity Nado 2 _ Episode 01.mp4`) failing inside OpenCV or exporters → pinned in Task 2 (`test_video_reader.py`) and Task 7 (`test_exporters.py`).
2. **Bright moving anime backgrounds (orange/tan/light patches) directly behind `白字黑边` text** causing false splits or missed detections → pinned in Task 3 (`test_subtitle_mask.py`) and Task 4 (`test_segmenter.py`).
3. **VFR timestamps, non-zero start PTS, and short fade transitions** causing timeline drift or overlapping cues (`end_ms > next.start_ms`) → pinned in Task 2 (`test_video_reader.py`) and Task 4 (`test_segmenter.py`).
4. **Consecutive flickering segments with identical or 1-char-noisy Chinese text & multi-line `\N` vs `\n` formatting** → pinned in Task 6 (`test_postprocess.py`) and Task 7 (`test_exporters.py`).
5. **User `.ass` templates with UTF-8 BOM / CRLF and safe overwrite confirmation when `.ass`/`.srt` already exist** → pinned in Task 7 (`test_exporters.py`) and Task 9 (`test_ui.py`).
